# CyberShield Guardian Hunt

Static classroom cipher game. GitHub Pages serves main branch root. No backend, student accounts, analytics or uploaded results. Use made-up team names only. Progress is stored in each browser.

Before live play, open Teacher setup on every iPad, confirm room names, permitted access and a safe target for 15 minutes. The class start code is a classroom cue, not secure authentication. There is no global Start/Stop or shared scoreboard. Answers and checkpoint codes are public in the source.

Actual iPad Safari, school-network access and checkpoint sign scanning need a classroom test. Offline functionality is not implemented.
