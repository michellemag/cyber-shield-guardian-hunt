# Cyber Shield Amazing Race Challenge

Static classroom cipher game. GitHub Pages serves the main branch root. No backend, student accounts, analytics or uploaded results. Use made-up team names only. Each team keeps one dedicated iPad, with progress saved only in its browser.

Play: https://michellemag.github.io/cyber-shield-guardian-hunt/

## Set up once on the teacher's device
1. Open **Teacher setup** with the classroom teacher code provided separately. The **Teacher README · codes & instructions** is inside this screen.
2. Check permitted room access, safe checkpoint placement and a route that fits the 15-minute station, including returning to the Forum.
3. Choose the digital or physical final challenge and enter a shared class start code. Use a classroom word, never a personal password. Physical mode requires prepared, print-tested shield pieces.
4. Confirm access and timing, then select **Create a new class link** and **Copy class link**. If copying is unavailable, select and copy the link field manually.
5. Share the full generated class link and the shared class code with every team. The plain website address alone does not carry the class settings.

## Start on each team's iPad
Open the shared class link, enter a made-up team name, select the warden-assigned route, enter the shared class code and select **Start live hunt**. Students do not need Teacher setup or the teacher code on their iPads.

The same class link resumes that browser's saved game. A newly created class link starts a separate fresh session without deleting earlier games; reopen an earlier link to resume its progress. Demo progress is separate: use **Back to class start** to leave practice. No routine reset is needed. The teacher's optional reset clears only the current game on that iPad.

## Limits and classroom checks
The teacher gate and class code are bypassable classroom controls, not secure authentication. Class links contain inspectable, non-secret settings. There is no global Start/Stop or shared scoreboard, and creating a new link does not remotely change iPads already playing. Answers and checkpoint codes remain public in the source.

Actual iPad Safari, school-network access, checkpoint sign scanning, route timing and physical shield printing/fit need classroom checks. Offline functionality is not implemented. Clearing browser data or using private browsing can lose progress.
